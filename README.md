# Webhook Relay Service

Сервис принимает события через HTTP API, сохраняет их в PostgreSQL и асинхронно отправляет получателям через Celery/Redis. Каждый исходящий запрос подписывается HMAC-SHA256.

## Запуск

```bash
docker compose up -d --build
```

При запуске API автоматически применяет миграции Alembic. После старта API доступен на `http://localhost:8000`, Swagger UI — на `/docs`.

Для локальной разработки скопируйте `.env.example` в `.env`, установите зависимости и выполните `uvicorn app.main:app --reload`. PostgreSQL и Redis должны быть доступны по адресам из `.env`.

## API

- `POST /api/v1/endpoints` — регистрация URL получателя. Секрет возвращается только при создании; сохраните его для проверки подписи.
- `GET /api/v1/endpoints/{id}` — информация о получателе.
- `POST /api/v1/events` — создать событие и поставить доставку в очередь; ответ `202` содержит `event_id`.
- `GET /api/v1/events/{id}` — статус события и все попытки доставки.
- `GET /health` — проверка PostgreSQL и Redis.

Подпись передается в заголовке `X-Webhook-Signature` в формате `sha256=<hex HMAC>`. Она вычисляется по точным байтам JSON тела запроса.

## Разработка

```bash
python -m pip install -e '.[dev]'
pytest
ruff check .
```

Временные ошибки сети, ответы `5xx` и `429` повторяются до трех общих попыток. Между попытками выдерживается 2 и 4 секунды; постоянный `4xx` завершает доставку сразу.
